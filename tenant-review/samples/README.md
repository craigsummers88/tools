# Sample reports

These reports were produced by Tenant Review against test data for two fictional organisations. Every name, domain, address and ID in them is made up.

GitHub shows the PDFs in the browser. To view an HTML report, open it, select **Download raw file**, then open the downloaded file in Edge or Chrome. The report is a single self-contained file with no external content.
